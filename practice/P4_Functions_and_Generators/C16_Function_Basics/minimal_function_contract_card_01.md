```python
def normalize_key(text):
    """Normalize a localization key."""
    return text.strip().lower()
```

| 合同维度         | 当前描述                                                     |
| ---------------- | ------------------------------------------------------------ |
| 输入             | 一个能够响应 `strip()`，且其结果能够响应 `lower()` 的对象    |
| 返回对象         | `text.strip().lower()` 的结果对象                            |
| 显示输出         | 无                                                           |
| 外部 I/O         | 无                                                           |
| 是否修改传入对象 | 函数代码中没有显式原地修改；对普通 `str` 不会修改原字符串    |
| 可能异常         | 对象不支持相应操作时可能出现 `AttributeError`；对象方法自身也可能抛出其他异常 |
| 业务含义         | 将本地化键去除首尾空白并转换为小写形式                       |

> 重要纠偏：不应未经证据直接把输入合同写成：`输入必须是 str`，因为从函数体实际采用的操作看，它直接要求的是：`对象支持 strip() 且 strip() 的结果支持 lower()`。当然，当前项目业务合同可以进一步规定“只接受字符串”。但是：`语言运行所需的最小操作接口` 和 `项目主动限定的业务类型` 不是同一个层次。
